# CCTV 샘플 영상

`src/data/scenario.js` 의 `cctvVideo` 경로에 대응하는 영상을 여기에 둡니다.

- `entry-a.mp4` — 장애물 o1 (차량 1대, 통과 가능)
- `entry-b.mp4` — 장애물 o2 (차량 3대, 통과 불가)

영상 파일이 없으면 CctvPanel은 자동으로 mock 오버레이(사전 분석 결과)로 폴백합니다.
실시간 탐지를 바로 시연하려면 패널의 "웹캠으로 실시간 테스트" 버튼을 쓰세요
(차량 사진/영상을 카메라에 비추면 COCO-SSD가 실제로 탐지합니다).

권장: 좁은 골목에 차량이 또렷하게 보이는 5~15초 클립(loop 재생). 세로/가로 무관.
