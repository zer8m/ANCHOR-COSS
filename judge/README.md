# judge — 통과 / 불가 / 관제이관 판정

```
통과  : 잔여폭 − 스케일여유 ≥ common.apparatus.required_width_m(차종)
불가  : 그렇지 않음
이관  : out_of_range 이면 무조건. det_collapse·occlusion_suspect 는 '통과'가 될 때만 (불가는 유지)
```

스케일여유는 모드별(`judge.MARGIN_M`, `judge.margin_m(스케일, 모드)`):

| 모드 | vp | bbox_h |
|---|---:|---:|
| gt (스케일 오차만) | 5 cm | 10 cm |
| det (운용) | - | **20 cm** |

20 cm 는 det 모드에서만 적용한다(점유·경계 오차까지 더해지는 운용 조건). 근거는 `decide.py` 주석과 아래 한계 참고.

## pipeline 에서 쓸 때

```python
from judge import decide, margin_m, PASS, FAIL, HANDOFF, SCALE_FALLBACK
v = decide(residual_m, apparatus_id, margin_m('bbox_h', 'det'), reasons)   # v.result ∈ {PASS, FAIL, HANDOFF}
```

- **det 모드는 이관 사유 처리 없이 `decide` 만 쓰면 S32·S36 에서 위험 통과가 발생한다.** 이 두 클립은 det 가 차를 못 봐서 도로 전체가
  비어 보이고(잔여폭 = 도로 폭), 사유 없이는 차종당 216건(필요폭 3.0 m 이상 차종)이 통과로 나온다. **pipeline 이 반드시 `reasons` 를 넘겨야 한다**
  (`judge.handoff` 의 `HandoffMonitor`·`frame_reasons`·`section_geometry` 로 감지, 프레임 집계). 사유를 붙이면 0건.
- `reasons` 의 사유: `det_collapse`, `occlusion_suspect`(통과가 될 때만 이관), `out_of_range`, `scale_fallback`(결과와 무관하게 이관).
- `SCALE_FALLBACK`: 카메라 설치 정보로 대체한 스케일 등 스케일을 못 믿을 때 pipeline 이 직접 넘긴다. `frame_reasons` 는 내지 않는다.
- 비교는 mm 단위 반올림: `round(잔여폭 − 여유, 3) ≥ round(필요폭, 3)` (부동소수로 `2.9 − 0.2 ≥ 2.7` 이 False 가 되던 문제 수정).
- 테스트: `python -X utf8 -m judge.test_decide` (pytest 불필요). `decide(residual_m, apparatus_id, margin_m, reasons)` 시그니처,
  `margin_m(scale, source)`, `PASS/FAIL/HANDOFF` 는 테스트로 고정.

## 이관 조건 (`python -X utf8 -m judge.handoff` 로 클립별 확정 비율 확인)

| 사유 | 감지 | 38클립 결과 |
|---|---|---|
| det_collapse | 신뢰도 <0.85 이면서 마스크 ≥20,000 px 덩어리 | S32·S36 100%, 나머지 0% |
| occlusion_suspect | 단면 행에 걸친 약한 덩어리(0.5≤신뢰도<0.85, ≥1000 px, 도로 안쪽)의 폭이 표준 승용차 예상 폭의 70% 미만 | S37 94%, 나머지 0% |
| out_of_range | 단면 지면 거리(`ground_distance_m`: 보정된 소실점·설치 높이·화각) > 32 m | S38(40.5 m) 100%, 나머지 0% (정상 클립 최대 30.6 m) |

프레임별 사유는 비대칭 래치로 확정한다(`HandoffMonitor`, 인과적): 최근 15프레임 중 3회 이상이면 확정, 연속 30프레임 무검출이면 해제.
S37 의 가림 덩어리는 마스크가 문턱값(1000 px) 근처에서 오르내려 대칭 50% 규칙이 6프레임씩 풀렸다.
S01(차 없음)은 신뢰도 높은 검출이 0건이지만 거대 덩어리가 없어 이관되지 않고 정상 판정된다.
S07(붙은 두 대)은 신뢰도 0.94 의 긴 박스라 이관하지 않고 점유를 넓게 보는 쪽으로 처리한다.

## det 점유폭 (`judge/occupancy.py`, `python -X utf8 -m eval.run --source det --scale bbox_h`)

- 도로 경계 px 는 CCTV 설치 시 1회 측량한 값이라고 보고 GT edge px 를 그대로 쓴다(det 에 도로 경계가 없다). 차종·정답 폭은 쓰지 않는다.
- 1단계: bbox 아래 변을 지면으로 옮기고 차 길이만큼 뒤로 늘린 직사각형. 옆면이 점유로 들어가 폭이 넓게 나온다.
  GT footprint 와 대조하면 항상 포함하지는 않는다(bbox 가 몇 px 어긋나면 `X ∝ 1/v′` 때문에 도로 중심에서 먼 차일수록 좁아진다).
- 2단계: 보정된 카메라로 bbox 를 표준 승용차 박스에 좌측 고정·우측 고정 두 번 맞춰 옆면을 뺀다. 맞춤이 안 되면(붙은 두 대·부분 가림·잡음) 1단계로 후퇴.
- **점유 기억 15프레임**: 최근 15프레임 점유의 합집합. det bbox 가 1~2프레임씩 도로 옆 물체와 합쳐져 아래 변이 튀면(S05 f40: 445 → 519)
  그 프레임만 보고는 차가 단면과 안 만나 +190 cm 위험 과대추정이 난다. 기억 없이는 위험 통과 261건(9차종 합), 있으면 0건. K=3 부터 0 이었다.
- |X| 비례 부풀림(ρ)은 위험 통과를 못 줄이고 우회만 늘려 채택하지 않았다(코드에서도 제거).
- 이상 박스(가로/세로 비 1.0~2.2 밖)를 이관하는 안도 비교했으나 효과가 없어(기억 없으면 261 → 90, 있으면 0 → 0) 넣지 않았다.

## lane 스케일 (옵션, 기본값 아님)
`python -X utf8 -m eval.judge_metrics --source det --scale lane` — 차선 소실점 + 설치 높이 카메라로 스케일·점유 맞춤. 여유 `MARGIN_M['det']['lane']` = 5 cm (제안값).
- 이관 안 된 프레임 최대 과대추정 **0 이하(-1.1 cm)**, base(bbox_h) +49.7 cm.
- 대신 3.3 m 차종 우회 0 → 143건, 9차종 합 우회 2750(base 20 cm) → 4222(lane 5 cm). MAE도 +5 cm(프레임 합산 64.98 → 68.57). 편향 중앙값 -23.7 → -38.9 cm.
- **기본값은 bbox_h, lane 은 `--scale lane` 옵션. 채택 전 우회 증가 원인(스케일이 작게 나오는지, 점유가 크게 나오는지) 조사 필요.**
- S32 는 lane 에서 `scale_fallback` 이 붙지 않는다(카메라가 만들어져서). `det_collapse` 로만 이관.

## 한계

- **S32는 "det 모드에서 차를 못 보는 경우"로 이관한다.** pitch −26° 카메라에서 78프레임 검출이 없고 화면을 덮는 거대 덩어리만 나온다.
- **det_collapse(20,000 px)·occlusion_suspect(70%)는 각각 한 클립에 맞춘 값이다.** 야간은 S36, 가림은 S37 하나뿐이라 다른 장면에서의 문턱값은 검증되지 않았다. S32 는 같은 문턱값에 우연히 걸린 것이지 따로 맞춘 것이 아니다.
- **out_of_range(32 m)는 정책이다.** 오차가 커서가 아니라 독립 검증 구간(T03 격자 5~30 m)을 넘기 때문이다. GT 스케일 평가에서 S38 의 bbox_h MAE 는 3.8 cm 로 나쁘지 않다.
- 거리는 보정된 스케일의 소실점(= 보정된 pitch)·설치 높이·화각으로 지면 전방 거리를 계산한다(GT 거리 대비 오차 평균 0.7%, 최대 2.7%). 예전 `f·h·D` 식은 평균 −2%, S32(pitch −26°)는 −12%(17.5 m)였다.
- **스케일 보정이 주차 차량을 표준 승용차(1.85×4.7×1.5 m)로 가정한다.** SUV·트럭·밴이 많은 골목에서는 보정 자세와 점유 맞춤 모두 오차가 커진다. 38클립은 승용 4종(세단·SUV 등)뿐이라 이 영향이 측정되지 않았다. det 점유 맞춤에서도 같은 가정을 쓴다(SUV 가 포함된 S05 에서 위험 쪽 과대추정 확인).
- **위험 통과 0건은 임계값과 멀어서 안 잡혔을 뿐인 클립이 있다.** det 모드 최대 과대추정은 S05 +50 cm, S29 +38 cm, S06 +37 cm 로 20 cm 여유를 넘는다.
  이 클립들의 정답 잔여폭이 어떤 차종 필요폭(2.7~3.3 m)과도 멀어서 위험 통과로 집계되지 않았다. 같은 오차가 임계값 바로 아래에서 나면 통과로 뚫린다.
  임계값과 무관하게 막으려면 여유가 50 cm 필요하다(3.3 m 차종 우회 204건). S05·S06·S29 는 데이터로 구분할 신호가 없어 이관하지 않고 그대로 둔다.
- **여유 20 cm 도 SUV·트럭은 못 막는다.** 근본 해결은 차 크기 가정 수정이다(다음 과제).

- **S25(10 m, 세단 1대)는 det 박스가 크게 어긋나는데 이관 감지에 안 걸린다.** det 가 차에 도로 옆 배경이 합쳐진 거대 덩어리
  (신뢰도 0.95, 마스크 146,000 px, bbox `[0,417,778,1014]`)를 내서 GT 박스와 IoU 0.34 이다(납품 `검증결과_읽어보기.md` 의 정합 비율 0.000).
  신뢰도 ≥0.85 라 검출 붕괴(저신뢰) 규칙에 안 걸리고, 가림·범위(10.3 m) 규칙에도 해당이 없다. 표준 승용차 맞춤도 이 박스에 그대로 맞춰 폭비(1.05)로도 못 잡는다.
  **이번에는 과소추정(안전 쪽)이다**: det 잔여폭 0.54 m vs 정답 1.81 m(−1.27 m)이고 정답이 모든 차종 필요폭 미만이라 위험 통과 0건.
  다만 합쳐진 덩어리가 항상 점유를 넓히는 쪽이라는 **방향 보장은 없다**. 규칙은 추가하지 않고 한계로만 기록한다(한 클립에 맞춘 문턱값이 되기 때문).

### 큰 차 한계 (S05·S06·S29): 이관 안 된 프레임의 과대추정
det · bbox_h · 2단계 점유 · 기억 15. 과대추정 = 예측 잔여폭 − 정답 잔여폭, 이관 사유가 없는 프레임(S05 150, S06 300, S29 150 프레임·단면).

| 클립 | 최대 | 중앙값 | >20 cm 프레임 | 차종 (GT) | det bbox ÷ GT bbox (폭 / 높이, 중앙값) | 표준 승용차 예상 bbox ÷ det (폭 / 높이) | 2단계 맞춤 성공 |
|---|---:|---:|---:|---|---|---|---:|
| S05 | +49.7 cm | +41.2 | 134 / 150 | 세단 Sonata + **SUV Sorento** (1.89×4.80×1.67 m) | 세단 1.11 / 0.93, **SUV 1.35** / 0.96 | 세단 0.99 / 1.03, SUV 0.90 / 0.98 | 세단 100%, SUV 70% |
| S29 | +37.5 cm | +29.1 | 89 / 150 | 세단 Sonata + **SUV Sorento** | 세단 0.94 / 0.98, **SUV 1.29 / 1.22** | 세단 1.07 / 0.98, SUV 0.91 / **0.85** | 세단 86%, **SUV 0%** (맞춤 오차 59 px > 15 px) |
| S06 | +37.0 cm | +3.5 | 32 / 300 | 세단 Sonata 2대 | 세단 1.12 / 0.88 | 세단 0.99 / 1.09 | 83% |

(표준 승용차 = `scale.bbox_calib.CAR` 1.85×4.7×1.5 m. 예상 bbox 는 det bbox 왼쪽 고정 맞춤 결과를 투영한 값. 표준 승용차 대비 SUV 는 높이 +11%, 폭 +2%.)

원인 추정 (측정한 것은 표의 수치까지이고, 아래 해석은 추정이다):
- **S05·S29 의 SUV**: det bbox 가 GT 박스보다 폭 29~35% 크고(S29 는 높이도 +22%) 겹침(IoU)이 0.5~0.6 이다. 분할 덩어리가 옆 세단·그림자·옆면과 합쳐진 것으로 보인다. 표준 승용차 투영이 이 박스에 맞지 않아 S29 는 맞춤 오차 59 px 로 1단계(bbox 아래 변)로 후퇴하고, S05 도 30% 가 후퇴한다. 위치가 어긋난 점유가 도로 중앙 쪽으로 밀려 GT 점유보다 좁아진다(예: S05 f115 단면 0, 점유 폭이 정답보다 약 50 cm 부족).
- **높이 가정**: SUV 가 표준 승용차보다 11% 높아 (X, Y) 맞춤이 가까운 쪽으로 쏠릴 수 있다. 높이만의 영향은 분리해 측정하지 않았다.
- **S06 은 SUV 가 없다**(세단 2대). 최대 +37 cm 는 f2 의 한 프레임이고 중앙값은 +3.5 cm 다. 먼 쪽 세단의 det 박스 높이가 GT 의 0.65배로 잘리는 프레임이며, 클립 시작이라 점유 기억이 2프레임뿐인 영향도 있을 수 있다(분리 검증 안 함). S05·S29 와 성격이 다르다.
- 세 클립 모두 정답 잔여폭이 어떤 차종 필요폭과도 멀어 위험 통과로 집계되지 않았다. 같은 오차가 임계값 바로 아래에서 나면 20 cm 여유를 넘는다.

## 다음 과제

- **SUV·트럭 등 큰 차 대응**: 현재 표준 승용차(1.85×4.7×1.5 m) 가정. S05(SUV) +38~50 cm. 차종 분류 또는 차 크기 추정이 필요하다.
- **스케일 보정은 설치 시 1회 또는 누적으로 가능**: 설치 정보·마커로 한 번 하거나, 여러 날 주차 차량의 bbox 를 누적해 보정한다. 판정(잔여폭 계산)은 차 한 대만 있어도 된다.
- 야간·가림 문턱값(20,000 px, 70%)을 클립 하나가 아닌 여러 장면으로 재검증.
